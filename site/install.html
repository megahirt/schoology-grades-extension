Install

Get it for your browser

The dashboard is a browser extension. It works on the Schoology website in your browser, not inside the Schoology phone app.

Store listings are on the way. Until they're live, teachers and parents on a laptop can try it early from the latest release (steps below).

Safari on MacComing soon

From the Mac App Store. On a school-managed MacBook, the school's IT team has to allow it first (details for IT).

Safari on iPhone and iPadComing soon

From the App Store. After installing, turn it on in Settings → Apps → Safari → Extensions and allow it on schoology.com. Then open Schoology in Safari (not the Schoology app).

The Schoology appNot possible

Extensions can't run inside other apps. Open Schoology in your phone's browser instead (Safari on iPhone, Firefox on Android) and sign in as usual.

Try it early (computer only)

For teachers and parents who'd like to try it before the store listings are live. This is a developer install: it's safe, but the browser will remind you it isn't from a store.

Chrome or Edge

  1. Download the …-chrome.zip file from the latest release and unzip it.
  2. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
  3. Click Load unpacked and choose the unzipped folder.
  4. Open Schoology and sign in. The dashboard tab appears at the right edge of the page.

Safari on Mac

  1. Download the …-safari.zip file from the latest release and unzip it.
  2. Safari → Settings → Advanced: turn on Show features for web developers.
  3. Safari → Settings → Developer: turn on Allow unsigned extensions (this resets each time Safari quits).
  4. Click Add Temporary Extension… and choose the unzipped folder.
  5. In Safari → Settings → Extensions, allow it on schoology.com.

On school-managed MacBooks these settings are usually locked. That's expected; see For schools.
